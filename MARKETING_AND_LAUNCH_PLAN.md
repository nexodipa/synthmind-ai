**Título:**
`I built an open-source document analysis tool using Gemini 2.5 & FastAPI (runs on free hosting tiers)`

**Cuerpo:**
```text
Hey everyone!

I wanted to share a side project I’ve been working on: SynthMind AI.

It’s an agentic document analysis tool designed to process dense PDFs, research papers, and legal contracts using Google’s Gemini 2.5 API with strict Pydantic schemas.

Key features:
- Core Concept & Argument Extraction (with direct textual quotes).
- Critical Audit Mode (spots internal contradictions and missing empirical evidence).
- Executive Synthesis Cards & Strategic Action Plans.
- Niche Specialization (Academic, Legal, Financial).
- Clean print-friendly HTML/PDF & Word exports.

The codebase includes both a FastAPI single-page app and a Streamlit dashboard ready for 1-click free deployment on Streamlit Cloud or Render.

Check out the repo here: https://github.com/JosueST-B/synthmind-ai

Would love to hear your feedback or thoughts on features to add!
```
